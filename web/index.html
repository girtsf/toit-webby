Toit Webby

flash & run Toit on an ESP32 — in the browser, over USB or Wi-Fi loading…

1 · USB device

Plug in the ESP32, click, and pick its serial port. The chip type is detected automatically.

2 · Flash Jaguar*

Builds the firmware in your browser and writes it over USB. One-time per device. Jaguar* is Jaguar plus mDNS (name.local), CORS for this page and captured program output, so with Wi-Fi set you can then work over the network.

3 · Wi-Fi device

Or open http://name.local:9000/ in the browser (any browser). From here, Chrome asks once to allow access to your local network.
